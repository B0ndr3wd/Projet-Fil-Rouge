# Projet Portfolio d'un Site Web - Solène Avril

Réalisation d'une page web pour une photographe d'art qui partage une galerie de photos. 

## Outils utilisées :

- **HTML5** : Structure sémantique de la page.
- **CSS3** : Flexbox & Grid CSS pour la mise en page responsive.
- **Google Fonts** : Typographies *Yeseva One* et *Montserrat*.
- **FontAwesome** : Icônes des réseaux sociaux.

## Fonctionnalités :

- **Galerie d'images**
- **Version PC** : Grille de 4 images par ligne.
- **Version Tablette** : Grille de 5 images par ligne.
- **Version Mobile** : Grille de 3 images par ligne.

## Installation :

1. Clonez sur la machine :
   ```bash
   git clone https://github.com/votre-utilisateur/projet-fil-rouge.git
   ```
2. Ouvrez le fichier `index.html`.
